# Tools Used

## Core Libraries

- **MNE** for EEG data loading, preprocessing, and epoching.
- **mne-icalabel + Picard** for automated ICA artifact labeling and cleanup.
- **scikit-learn** for CSP features, classifiers, and cross-validation.
- **NumPy / SciPy / Pandas** for numerical operations and tabular reporting.

## Visualization

- **Streamlit** for the interactive UI and workflow controls.
- **Plotly** for waveform and confusion matrix visualizations.

## Infrastructure

- **Docker** for containerized deployment.
- **YAML** configs for experiment and workflow settings (planned).
