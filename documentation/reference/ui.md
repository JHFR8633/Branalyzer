# UI Modules

This page documents the Streamlit UI helpers in `Branalyzer/src/app/ui/`. These modules render the visible sections of the app and read from session state.

## `workflow_controls.py`

Renders the workflow stage controls and the load-data dialog.

`render_load_data_dialog()`
Shows the modal for selecting a data source and either a PhysioNet subject or EDF upload.

`render_stage_controls(...)`
Renders the Load Data, Run Preprocessing, and Run Models buttons and their status blocks. It also processes pending load requests.

`render_stage_status(is_complete, loading_label, complete_label)`
Provides a stable status placeholder that looks consistent between loading and completed states.

## `signal_inspection.py`

Renders the signal inspection section and its fragment-scoped interactions.

`render_signal_inspection(picks)`
Builds the signal inspection area, including downsample controls, window sizing, and tabs for raw, filtered, and ICA-cleaned views.

`render_waveform_navigation(duration)`
Shows step and jump controls for moving through the waveform window and synchronizes state.

`maybe_autoplay_waveform(duration, frame_speed)`
Advances the waveform window during autoplay and reruns only the fragment.

`render_waveform_plot(...)`
Draws one waveform plot using Plotly data generated by the waveform pipeline.

`render_waveform_title_row(title, plot_key, subtitle=None)`
Shows the plot title and the shared play or pause toggle.

## `results.py`

Renders model benchmarking summaries and the event log.

`render_model_benchmarking()`
Displays top-line metrics for the best model, a comparison table, and per-model confusion matrices.

`render_confusion_matrix(result, max_cm_value)`
Renders a single confusion matrix heatmap.

`render_event_log()`
Shows a per-epoch prediction table and colors each model cell by correctness.

`build_event_log_comparison_table(results)`
Builds the event log table and a lookup used for styling.

`highlight_model_prediction_cells(row, match_lookup)`
Applies per-cell background color to indicate correct or incorrect predictions.

## UI State Touchpoints

Common `st.session_state` keys used across UI modules:

- `data_loaded`, `preprocessing_ready`, `models_ready`
- `raw_view`, `filtered_view`, `ica_view`
- `available_channels`, `default_channels`
- `waveform_window_start`, `waveform_window_size`
- `waveform_ds_factor`, `waveform_frame_speed`

## Technical Notes

- `render_signal_inspection` is wrapped in `@st.fragment` to avoid full-page reruns when changing waveform controls.
- Waveform plots are generated through the Plotly pipeline in `ui/waveform.py`.
- The event log table uses a pandas Styler to color prediction cells.
