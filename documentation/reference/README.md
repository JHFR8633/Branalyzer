# App Reference Index

This section is the module-level reference for the Streamlit application. Each page starts with what the module owns and then lists key functions in that context.

## Reference Pages

- `app.md` - Streamlit entrypoint and top-level handlers.
- `ui.md` - UI rendering modules and their responsibilities.
- `workflows.md` - Workflow orchestration and session state helpers.
- `preprocessing.md` - EEG preprocessing helpers and assumptions.
- `models.md` - CSP feature extraction and model pipelines.
- `waveforms.md` - Plotting pipeline for waveform visualization.
- `data_ingest.md` - Data loading helpers for PhysioNet and EDF uploads.
- `schemas.md` - Shared dataclasses used across the pipeline.
