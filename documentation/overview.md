# Project Overview

Branalyzer is an accessible EEG analysis and benchmarking dashboard designed to make brain-computer interface workflows easier to explore. It packages data loading, preprocessing, model evaluation, and visualization into a guided, interactive experience so users can learn by doing and compare approaches quickly.

## Problem Being Solved

EEG/BCI tooling is often fragmented and intimidating for newcomers. Datasets, preprocessing, and evaluation typically live in separate scripts and notebooks, making it hard to iterate or understand cause-and-effect. Branalyzer reduces that barrier by offering a single place to load data, run a standard preprocessing path, benchmark classic ML models, and inspect both signal quality and model performance.

## Why It Matters

Branalyzer helps teams and learners experiment with BCI workflows without needing to build custom pipelines from scratch. It makes the relationship between preprocessing choices, signal quality, and model performance visible, which is critical for building intuition in EEG analysis.

## Goals

- Make EEG exploration more accessible to students and first-time practitioners.
- Support quick experimentation with preprocessing and model choices.
- Provide transparent, reproducible benchmarking and visual feedback.
